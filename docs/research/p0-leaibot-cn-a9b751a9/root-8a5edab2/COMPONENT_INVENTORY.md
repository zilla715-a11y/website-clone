# Component Inventory

1. `SiteHeader` — logo, expandable channel navigation, order/profile actions.
2. `HeroIntro` — fixed prefix and time-driven rotating phrase.
3. `Composer` — textarea, thinking toggle, scope controls, more menu, media/send controls.
4. `ContentGallery` — four-state tabs, animated ink, three-card grid with real product images for the default state.
5. `LegalFooter` — fixed regulatory line.

Page assembly remains a Server Component. The four interactive sections define narrow Client Component boundaries.
