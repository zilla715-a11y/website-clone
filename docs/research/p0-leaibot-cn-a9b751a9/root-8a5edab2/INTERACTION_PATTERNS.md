# Interaction Patterns

- Navigation reveal: hover/focus/click expansion with spring easing.
- Headline: timed word rotation with 0.34s vertical fade.
- Composer: local toggle, expanding menu, textarea auto-height, submit-state feedback.
- Gallery: click-to-switch data sets; moving active indicator; 0.2s grid transition.
- Cards and icon buttons: short hover elevation or lavender background transitions.
- Scroll interaction: none on the inspected route.
- Motion accessibility: transitions effectively disabled under reduced-motion preference.
